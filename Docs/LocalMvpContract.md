- enum MissionPhase { Briefing, Playing, Paused, Won, Lost }
- LocalMission : MonoBehaviour: public MissionPhase Phase {get;}; public int DepositedCount {get;}; public int RequiredLoot {get;} (3); public float RemainingSeconds {get;}; public float Alarm {get;} (0..1); public string StatusMessage {get;}; public LootCarrier Carrier {get;}; public FpsController Player {get;}; public event System.Action Changed; public void Configure(FpsController player, LootCarrier carrier, float duration=300f, int requiredLoot=3); public void StartMission(); public void TogglePause(); public void RestartMission() (recarga escena); public bool TryDeposit(LootCarrier carrier); public bool TryExtract(LootCarrier carrier); public void RaiseAlarm(float amount); public void Tick(float deltaTime) (solo Playing, determinista); public void Fail(string reason).

- PatrolGuard : MonoBehaviour: public void Configure(LocalMission mission, Transform[] route); patrulla por ruta libre de obstáculos diseñada; visión con línea de visión e incremento de alarma, agacharse reduce alcance; alarma máxima causa derrota; se pausa fuera de Playing. No NavMesh requerido, evitar atravesar paredes mediante layout/raycast. Visual propio procedural por builder.
